# 特殊工法工作台

供現場人員使用的特殊工法計算與製作工具。手機輸入實際尺寸，查看計算結果與定位示意；電腦可列印尺寸工單與適用的 1:1 紙樣，帶到現場標線、製作與試配。

配管放樣是目前已實作的工法之一。產品將依工作內容擴充不同工具，各工具提供自己的尺寸輸入、製作基準與輸出，不要求所有工法都使用主管／支管的接頭設定。

| 配管接頭與補強板 | 魚口、母材開孔、板片與定位紙樣 | 已提供，詳見下方適用範圍 |
| 鋼構支材貼合 | 圓管、方／矩形管、H／I 型鋼、角鋼與槽鋼端部放樣 | 已提供 |

新工法的共同操作方向是「選工法 → 填尺寸 → 看結果與圖示 → 需要時列印」。手機優先顯示現場需要的尺寸與示意；電腦提供紙樣、工單與檔案匯出。每種工法按其用途決定是否提供 3D 或 1:1 紙樣。

## 統一入口

雙擊專案根目錄的 `啟動工作台.cmd`，會啟動本機服務並自動開啟工具首頁（使用期間保持該視窗開啟）。已啟動時沿用同一個服務。首頁選「插管與支材放樣」、「偏移配管」或「桶槽估料與捲板」；三個工具上方都有相同的切換列。

| 檔案 | 用途 | 本機完整入口 |
|---|---|---|
| `dist/index.html` | 工具首頁 | `http://127.0.0.1:4173/` |
| `dist/joint.html` | 插管與支材工具（原首頁功能） | `http://127.0.0.1:4173/joint.html` |
| `dist/offset.html` | 偏移配管工具 | `http://127.0.0.1:4173/offset.html` |
| `dist/tank.html` | 桶槽估料與捲板工具 | `http://127.0.0.1:4173/tank.html` |

HTML 是頁面外殼，計算、互動、Worker 與 3D 由旁邊的 JavaScript 模組載入。完整工具需透過 HTTP 開啟。直接雙擊 HTML 時會顯示啟動指引；模組載入失敗則顯示重新載入入口，不讓未完成載入的工具看起來仍可操作。工具各自使用獨立的專案儲存鍵，既有工具保持原鍵；在同一個 `127.0.0.1:4173` 來源開啟不會清空已存尺寸。`localhost` 與其他連接埠屬不同瀏覽器儲存來源。

入口驗收：完整 452 項測試通過，包含 file 模式在載入模組前切換啟動指引、模組失敗時顯示修復入口，以及同一 HTTP 服務供應首頁、兩工具、依賴圖與 Worker。Windows PowerShell 實測啟動成功、重複啟動沿用同一服務。瀏覽器實際操作共同首頁、工具互相切換、插管 3D／三頁魚口紙樣預覽，以及原 XYZ 尺寸的偏移候選與五頁加工單。驗證瀏覽器禁止 file URL，因此直接開檔案的分支以啟動邏輯測試確認。

## 2026-10 偏移配管介面整理

端口輸入區的左圖預設為可拖曳旋轉、滾輪／雙指縮放的 3D，呈現既有 A／B 管口、朝向及目前選定接法的實際彎頭、直管與零件。端口位置頁同時顯示 XYZ 量測線；焊口留料頁使用加工單的 J 編號，點標籤可直接修改該口預留。切換設定頁或重算幾何會保留旋轉方向與縮放比例，另有立體／正視／俯視／側視、縮放與置中按鈕；鍵盤方向鍵旋轉、加減鍵縮放、F 置中。3D 拖曳只改視角，不修改尺寸。

量測標記點與修正後端面中心分開繪製，不將空白尺寸當作零。接法失效時撤下組立模型，尺寸與朝向有效時仍可旋轉查看兩個管口；3D 載入失敗則回到可操作的尺寸圖並提供重試。尺寸圖保留 XYZ 參考盒、尺寸按鈕及拖 B 粗調位置；方向投影維持右手座標。手機保留原生尺寸與接合口按鈕；接合口較多時 3D 只顯示選中編號，完整編號仍在欄位旁。模型為位置與接法預覽，組入及焊接操作空間仍由第二步的組立檢查核對。

統一間隙只修改目前接法的焊口，含新增焊口及零件的焊接端，保留螺栓接合預留。修改時沿用已選彎頭與方向，以原有長度分配器重新求直管並驗證閉合、最短管段與指定零件。若放不下，保留欄位供修正、撤下無效接法並停止出單，不改選另一配置。若多個 J 口共用同一新增間隙設定，欄位明示其共用編號。新增數值與互動回歸涵蓋五焊口、零件焊／螺栓分離、四彎頭直段保留、無效間隙與帶正負號的量測。

第二步分為「接法預覽」及「組立檢查」。預覽保留 3D 與三個關鍵數字，零件明細預設收合；組立再分「搬入演練／現場條件／逐口淨空」，一次顯示一組任務，切換時保留尚在編輯的值。現場尺寸以原管、工具及障礙物分組；狀態先顯示摘要和一個可直接定位的待辦，完整問題仍能展開。手機以圖面和單組輸入為主，桌面組入圖與設定並排。

搬入演練從起點顯示，提供「看起點／看對口」。讀值包含剩餘毫米數、起點側與實際送入方向；例如從右側 −Y 起步、100 mm 行程播至 63%，就是沿 ＋Y 已移動 63 mm、距對口 37 mm。短行程只標示為最後一段對口演示，完整搬入仍待核對。內部焊口圈跟隨預組件移動，收口則分別呈現移動端面與固定／目標端面；方向圖與 3D 共用位移及接合位置判定。固定管口使用原生標籤與引線，零件編號可展開；指定零件的外包未填時直接標示未填。檢查條件改動後會停播、停用舊進度，更新後返回演練會重建目前圖面。

現場環境沒有自動掃描。搬入畫面明示目前只有管路與 A／B 既有管，提供「加入／查看現場物件」入口；需要核對牆、梁、其他管線或設備時，再從 A 口基準量入平面／箱體包絡。新增物件的尺寸預設留白，不會憑空產生障礙物；未加入的環境不會被判定碰撞，也不能因場景空白視為已通過檢查。動畫尚未實作撞擊瞬間停播。

零件編輯改成圖像類型選擇、沿 A → B 的位置圖與可用直線卡片，套用前即時核對剩餘直管、焊口及螺栓接合數。需換接法的位置明示原因；細部接法、預留與定位預設收合，套用按鈕固定在對話框底部。切換類型及計長方式保留本次已填的實測值，錯誤會定位到缺少的尺寸欄位。

偏移配管法蘭組可選 ASME／ANSI NPS、Class、WN／SO 與接面，提供 Class 150／300 捷徑。常用 WN／RF 參考總長＝兩支法蘭各自的端面占長（已含 RF）＋一片**壓緊後**墊片厚度；墊片需明確填入，兩端焊口預留另計一次。參考表與桶槽共用，涵蓋 NPS ½～12 的 15 種常用尺寸。SO 管子穿入法蘭，不用兩倍法蘭長直接扣管；SO、未收錄規格及其他組合以整組實測總長處理。參考規格須與目前管 OD 相符；異徑配對件需一併實測。JSON、CSV 與加工單保留規格及實測／參考來源，舊專案不自動改成參考計長；參考值仍需供應商圖說或實物覆核。

按鈕改為一致的主次層級、線條圖示及明確選取狀態；組立選法使用管段圖卡，3D 採柔和底色及圓角標籤。保留完整計算、警示、量測確認與出單內容；版面偏好不寫入工程尺寸。圖示集中在 `offset-ui-icons.js`，樣式在 `offset-refinement.css`。

## 2026-10 偏移配管：組立順序與接合空間

第二步「選接法」切到「組立檢查」，可核對裝得進去、焊不焊得到。不增加零件或焊口，也不改原有接法排序；選定的 2～4 彎頭、直管、閥與法蘭配置共用檢查及輸出資料。

- **怎麼裝**：整段在工作台預組後搬入，或兩側先裝、最後補選定的一件。逐步指定從前／後／左／右／上／下或自訂斜向送入，填實測行程；3D 可播放、暫停、拖曳進度與旋轉。點現場接合口會切到該口施作的步驟；當步接合完成後才裝下一步。
- **過不過得去**：既有 A／B 直管填檢查長度，閥／法蘭填含突出物的最大外包直徑。障礙物以修正後 A 端面中心為 0，可建最多 12 個箱體或禁止進入的平面半空間。用實體外包及整段連續直線掃掠檢查，不只取動畫幀；彎頭採含弦差餘量的保守膠囊包絡，重疊表示需調整或實物精查。未填行程、只填不足以脫離目標包絡的短行程，或環境未確認，都保留待核對。
- **焊不焊得到**：手工電焊／氬焊的徑向及 A／B 側軸向需求自行填；螺栓接合另填扳手需求及置入／孔位確認。現場口逐一量四個完整 90° 象限及兩側軸向的最小淨空，涵蓋整個所需操作範圍。工具需求也與當步已裝零件及障礙物交叉核對；後續尚未裝上的零件不會提前擋住施焊。相鄰彎頭與零件細部接近性由實測確認。工作台預組口另核對翻轉及接近空間。
- **缺資料與輸出**：未量與明確 0 分開處理。改尺寸或接法會清除逐口量測與確認；改工具需求或組立順序會撤下相關確認。問題可直達工具／現場欄位或焊口。首頁、A4／A3 加工單與 CSV 顯示同一狀態；長明細分頁保留全部。JSON v7 保存選定接法、搬入設定、障礙物、工具及量測，仍支援 v1～v6。

此檢查限固定姿態的直線搬入；不自動搜尋旋轉繞入、不校核吊具／人員通道、彈性強拉、焊接變形或力學承載。須由現場確認完整環境與起始位置，綠色僅表示已輸入條件核對完成。未做實管試裝、現場施焊或印表機實印，不能取代圖說、WPS 或施工核准。工具空間不採假定標準值；實際焊具姿態參考 [Miller TIG 操作指南](https://www.millerwelds.com/en-US/resources/knowledge-hub/tig-welding/how-to/guide-to-tig-welding-basics)。

新增 29 項幾何／狀態／資料與輸出測試，包括 1 mm 中途障礙物、固定端軸向送入受阻、管身可過但焊具受阻、連續角度操作包絡的獨立密集取樣、不同順序的接合時機、未知／0、過期量測、A／B 原方案及多彎頭重開。全套 612 項中 611 通過、1 項原有跳過、0 失敗。瀏覽器驗證完整填寫、播放／暫停、錯誤修正、3D 切換步驟、JSON／CSV 下載及三彎頭重開；320／390 px 無頁面水平溢出，四彎頭加 12 個障礙物的 28 頁 A4 工單無頁尾重疊，另核對 A3。

## 目前已提供的工具

### 桶槽估料與捲板

從共同首頁開啟「桶槽估料與捲板」。可選立式或臥式圓筒；上下（臥式為 A／B）端各自選開口、平板、錐形、拱頂、2:1 橢圓、碟形（ASME F&D、Klöpper、Korbbogen 或自訂）或半球。先選已知的直徑＋直段高度、直徑＋幾何容積，或直段高度＋幾何容積，第三項自動反算。點桶槽圖上的尺寸可直接回到欄位；圖上以藍色顯示使用液位，另有旋轉／自動旋轉／透視 3D（含支撐、梯台、夾套、吊耳等附件）。

- 直徑可用內徑或外徑，外徑會扣兩側筒身板厚。容量使用內部幾何尺寸（含兩端容積，未計接管占容）；「液位容積」工法列出使用液位與完整液位—容積表（臥式含封頭部分容積）。
- 直段高度定義為兩端切線間距；成形封頭的直邊與對接間隙、錐體與半球的對接間隙從筒身板料扣除。瓜瓣拼焊的半球沒有直邊。
- 捲板中面周長近似為 `π × (內徑＋筒身板厚)`。按原板寬／長分圈、分片，對接間隙從成品長／高扣除；每邊修邊留料另加回毛坯。預彎、夾持、焊接收縮與接縫錯位依機台、圖說及 WPS 確認。
- 原板可選 4′×8′（1219.2×2438.4 mm）、5′×10′（1524×3048 mm）或 5′×20′（1524×6096 mm），並可按供應商實際尺寸自訂。[國際英尺按 304.8 mm 換算](https://www.nist.gov/pml/us-surveyfoot)。既有 1500×6000 等公制原板保持自訂尺寸，不冒用英尺板型名稱。
- 可比較長邊沿圓周的「橫向分圈」與長邊沿高度的「直立分片」。各板型按等高分圈、等長分片估算實際張數、採購重量、毛坯利用與餘料、筒身縱縫／環縫及焊縫長度；比較徽章僅在三種板型的完整配置中選取，不代表所有排法的最優解。餘料估重包含刀縫及圓板外側廢料，不代表全部可再利用；不完整配置只計入已排部分。
- 彩色 S 板片編號連結筒身展開圖、原板排料與可旋轉的 3D；點板片查看來源原板座標、成品／毛坯尺寸與從底部算起的圈位。相鄰圈可示意錯開半片節距或對齊縱縫；角度以第 1 圈起縫為 0°，俯視順時針。未校核規範縫距、接縫交會、接管及補強避讓，不能把此示意當作正式製造圖。手機另用放大的分片圖和至少 46 px 高的板片按鈕。
- 原板採購按矩形包絡作順序切割排料，含刀縫並嘗試共用同厚度餘板（扇形板、瓜瓣、拼板與附件板件各自以實際包絡排入）。每片有原板座標且不得重疊；配置未保證最少張數。圓板放不進原板時可一鍵改用拼板。
- 成形封頭（橢圓、碟形、半球）預設按成形件採購；若供應商提供毛坯圓徑可納入排料，另列等面積毛坯僅供採購參考。重量按中面曲面與厚度概算，不含成形減薄；可填每只實重覆蓋估值。
- A4 估料單包括主體尺寸、零件、捲板、板型比較、筒身組立、設計條件及排料示意；組立表列前 12 片，CSV 保留全部板片圈位、來源原板及板上包絡座標。JSON 專案獨立保存在 `special-method-tank-v1`，不混入配管專案；新增板向／縱縫設定可儲存，舊專案自動補上預設值。

**規範範圍：** [ASME VIII-1 官方說明](https://www.asme.org/codes-standards/find-codes-standards/bpvc-viii-1-bpvc-section-viii-rules-construction-pressure-vessels-division-1)涵蓋壓力容器的設計、製造、檢驗、試驗及認證；其範圍摘要提及超過 15 psig 的內／外壓，工具不以此數字自動豁免真空或低壓容器。[API 官方目錄的 API 650 範圍](https://www.api.org/-/media/files/publications/2025-catalog/06_refining_2025.pdf)有立式圓筒、地上、焊接、槽底均勻支撐等條件，不能視為所有常壓槽的通用規範。適用版次、設置地法規與合約要求由專案確認。

設計條件頁記錄內壓、外壓差、設計溫度與最低設計金屬溫度、材料、介質、腐蝕裕量、接頭效率、規範版次與設置地等。製作工法頁列出規範條件參考與數量估算（射線處數、尺寸允差、填入 MAWP／LSR 的試壓參考、PWHT 板厚條件與熱循環；未依輸入版次切換規則），支撐與吊耳只算靜力分配。尚未實作許用應力資料庫、最低板厚／平板端部／外壓失穩、開孔補強計算、風／地震、支撐與吊耳強度或認證判定。所有輸出明示「估料用板厚；尚未完成強度與規範審查」；不是 ASME 合格證明或正式承壓製造圖。

管嘴／法蘭頁可新增最多 30 個管嘴。先在筒身圖選高度、俯視圖選方位，再輸入實際管外徑、管厚、外伸、內凸及法蘭資料；圖面亦可用方向鍵粗調，Shift 加大步距。支援筒壁徑向穿入，以及各種端部的軸向管嘴（曲面端部依當地深度計算管長）；可設為人孔（蓋板、吊桿或鉸鏈）並填補強板外徑與厚度。斜插尚未納入。新增尺寸只是操作示例，不是 ASME 型錄尺寸。

外伸由近側外壁沿管嘴軸量到法蘭密封面或裸管端。帶頸對焊法蘭從管長扣其對焊端至密封面的占長及一次對焊間隙；平焊套入不扣法蘭占長，只扣一次指定的管端退縮；退縮 0 表示管端與密封面齊平，正值朝槽壁方向退縮，焊接位置依圖說／WPS。筒壁魚口按內壁曲率列最短、最長及最長包絡加總留料的先備長度，重量未扣魚口切除。法蘭單重 0 表示未提供，另列缺重只數；主體估重未扣開孔，容量未扣內凸管嘴。

法蘭設定以 WN 對焊／SO 平焊／裸管端圖卡選接法，分開記錄 ASME B16.5 的 NPS、Class、RF／FF／RTJ 密封面及材質。可點尺寸示意上的外伸、法蘭占長、外徑及間隙／退縮回到欄位；手機另有大尺寸按鈕。管長扣料會即時顯示，錯誤提示可定位到欄位，規格、尺寸來源與 SO 退縮亦保留在 JSON、CSV 及 A4 單中。舊規格文字保留為業主圖說／型錄備註。

常用參考表取自 Texas Flange [Class 150](https://texasflange.com/products/flange-dims-weights/ansi-b16-5-forged-flanges/class-150/)／[Class 300](https://texasflange.com/products/flange-dims-weights/ansi-b16-5-forged-flanges/class-300/)，目前含 NPS ½～12 的 15 種常用 WN／SO、RF 尺寸。按廠商圖示把另列的 1/16 inch RF 高度加一次至盤厚與面到端總長；英寸表精度有限，換算值僅供估料與外形參考，供應商圖說／實測優先。套用只更新外徑、盤厚、總長，法蘭單重改為待填，保留管嘴實測外徑／管厚；沒有管徑／Schedule／內孔或螺栓資料自動配套。其他尺寸、Class、FF／RTJ 可記錄並輸入實測尺寸，未收錄時停用帶入，沒有自動代用；已帶入後改規格會提示重新套用或改用實測。Class 不直接等於允許壓力，壓溫額定仍須依材質／溫度正式校核。

管嘴位置會顯示在筒身板片展開、可旋轉 3D 及估料單；3D 為組立外形示意，沒有螺栓孔或槽壁開孔實體切除。開孔超出板邊、伸出不足等錯誤可直接定位至欄位，修正前停止匯出。開孔包絡碰到筒身接縫、其他開孔或法蘭包絡時提示核對；這些是幾何提示，沒有套用規範最小縫距。法蘭規範／材質／等級／密封面及補強／接管載荷可記錄，開孔補強、局部應力、管線載荷、法蘭壓溫額定、螺栓／墊片與 ASME 合規尚未校核。補強板依填入外徑沿筒身中面展開下料並估重；是否需要補強、螺栓、墊片或盲板仍依設計。

管嘴編輯分成「位置／管料／法蘭接法」三個短操作區，上方清單保留目前選取管嘴；同一組輸入控制項在任務間移動，不維護第二份資料。法蘭任務顯示剖面、端面外伸 A、占長 L、外徑 D 及焊口間隙／SO 退縮，可點圖或尺寸卡回到欄位。手機用可展開的「管料先備…／圖面」入口保留剖面與結果，避免先捲過整張圖才能填規格。錯誤提示會切到對應操作區、展開欄位所在摺疊區並聚焦。

「常用規格」與「實測／圖說尺寸」分開操作。舊專案的自訂 OD、占長、盤厚與單重保留，瀏覽規格不自動覆寫；明確帶入參考尺寸後，切換已收錄的 Class／WN／SO 才同步更新三項法蘭尺寸。相同尺寸重複選用不清掉已填單重；實際換尺寸則改為單重待填。未收錄的 Class、尺寸或接面保留原值並明示尚未更新，不代用其他規格。手動修改尺寸會撤下參考表來源。新增管嘴使用 NPS 2／Class 150／WN／RF 的操作示例，仍須按圖說選用；此預設不作壓溫額定選型。

管料增加公稱吋數選單，只帶入管 OD，不猜管厚或 Schedule。法蘭可沿用已知管嘴口徑；不同口徑顯示差異，只有使用者點「管嘴也改為…」才修改管 OD。自訂 16 mm 等非表列外徑不會吸附到近似吋數。新增回歸涵蓋規格自動更新、WN／SO 扣料、舊實測保留、單重、未知尺寸、欄位導引及專案／工單來源保存。

- 圖像操作：點 A／B 口用箭頭圖卡選朝向；點 X／Y／Z 尺寸填精確數值。立體／正視拖 B 粗調 X、Z，俯視粗調 X、Y，側視粗調 Y、Z；拖動取整毫米，現場實測值仍須精確填入。第一步依序確認位置、彎頭材料、焊口留料，兩端相同供料只填一次。材料以 90°／45° 原件或整支件圖卡選擇，點彎頭圖上的尺寸展開精確輸入。
- 修正引導：空白或不合法的尺寸會開啟對應分頁及收合設定、捲到欄位並聚焦，圖上同時標示問題位置。端口資料完整但兩彎頭接不成時，直接進入接法搜尋，原兩彎頭的角度與管長限制另列在說明中；不把單一配置失敗當成量測輸入錯誤。不自動改實測 XYZ、供料種類或施工下限。比較條件錯誤也可直接前往該條件。
- 接法有實際路徑縮圖與焊口數比較。「展開接法，點圖選擇」會打開列表並顯示選擇提示，點選後帶回組立結果；尚未選定接法時點「看加工單」會帶到選擇，不會留下空白加工頁。「選接法」直接顯示可拖曳旋轉的 3D，支援滾輪／雙指縮放、自動旋轉／暫停、縮放按鈕與置中；方向鍵旋轉、加減鍵縮放、F 置中。點管身或零件編號開啟該件加工，拖曳與雙指操作不觸發加工跳轉；也可切回零件示意。切角側視與端面分開顯示，端面可點周向分點，顯示從保留端面沿母線量距（含自帶直段）；完整分點表另行展開。加工頁的單件 3D、試組差異、資料來源及其他輸出預設收合。

- 座標為右手系：**前＋X、左＋Y、上＋Z**（往右偏填負值），與 3D、俯視／側視圖及工單「外背順時針」轉向一致。預設從兩個既有管口量 X／Y／Z；可選端面中心，或現場標記點加各端到中心的 XYZ 修正。端口方向可選 ±X／±Y／±Z 或自訂向量（朝既有管口外），反算 A／B 兩個彎頭角度及中間直管。平行、垂直或斜向管口使用同一套端面閉合檢查，不假設兩個彎頭一定等角。
- 保留舊的理論交點模式：平面與 rolling offset、正／負高低差與側移。已知角度算管長，或已知 Run 反算等角彎頭。切換基準後要重新量尺寸，舊專案不會自動把理論交點解讀為管口。
- A／B 各自選現成彎頭或原彎頭切角。現成件使用實測／型錄 Ta／Tb（中心至接合端面，已含自帶直段，不再另加保留端直段；建議搜尋也不把現成件對半切）並核對角度；切角件使用實際中心線半徑 Rc 與原件角度（最大 90°）。90° LR 可明確按鈕帶入既有 Benkan 尺寸作理想半徑，不把 45° 中心至端面尺寸當成半徑。
- 手邊原彎頭預設 90°。Rc 可按型錄直接填，也可用捲尺量原件完整外背或內腹弧長，按原角度反算；量弧長時排除端部直段。保留端直段分 A／B 輸入，切角尺寸表從弧面起點量，從端面量時加該端直段。
- 四個焊口分開輸入：G1 既有 A 口、G2 A 彎頭與直管、G3 直管與 B 彎頭、G4 既有 B 口。G1／G4 在端口反算時沿各端管軸扣除；中間直管長 = Travel − Ta − Tb − G2 − G3。另外指定兩端修磨留料與最短焊接管段，分開顯示先下料長／成品長。0 表示明確指定 0，空白不代表 0；間隙與施工下限依 WPS 指定。
- 原件角度不足、無正長度直管、不符合指定最短管段、端口無法閉合或現成角度不符，會停止該配置的加工輸出。端口資料完整時可繼續搜尋多段接法，選定通過閉合檢查的候選後使用其加工單；沒有自動加入強拉補償。
- 原方案及多彎頭候選都有整組 3D；多段接法可依 E／P 編號切換各彎頭與直管，顯示實際接合端面、自帶直段及各焊口。切角彎頭另有切面、保留／切除區與分點母線。加工頁依所選接法顯示模型，不再受原兩彎頭方案失敗影響。無 WebGL 時仍保留尺寸、SVG 示意與列印。
- A4／A3 加工單：備料總表、XYZ 正投影、四個焊口、兩端外背朝向、彎頭保留／切除圖、捲尺外背／內腹／左右量距、完整 4／8／12／24 分點表與切割修磨步驟。另有 1:1 分點量尺（雙方向 100 mm 校正尺、10 mm 拼接重疊）、CSV 與 JSON 專案。
- 「實際切角／試組差異」可輸入實際 A／B 角度、直管成品長，或將角度取整至 0.5°，比較剛性自由組立的末端 XYZ 差與管軸角度差。保持原彎曲方向及兩彎頭相對轉向；不計彈性變形、應力、支撐或設備接管負載。沒有提供可拉毫米數或允收判定，不能拿幾何差距當作吊鍊可拉量。
- 「比較其他接法」固定端口位置及朝向，保留成立的原方案，另外搜尋整支／對半原彎頭與新增直管的接法。新專案預設焊口少優先、最多四彎頭及 8 個焊口（含兩端）；焊口與特殊切角數相同時，先比較繞出範圍及管長，再比較對半切次數。相對成立的原接法比較實際焊口數。舊專案或自行指定的較低上限保持不變，畫面說明實際可容許的彎頭數，提供明確按鈕放寬搜尋至四彎頭、8 焊口。可自行改加工容易／空間排序、焊口上限、最多 2／3／4 個彎頭、搜尋最短管段、新增焊口間隙及繞出範圍。比較只提出建議，原尺寸保留；使用者明確點選備選後，組立圖、加工頁、列印及 CSV 使用該備選。修改尺寸會清除過期建議。
- 每個建議列 E／P 材料順序、彎頭角度、直管成品／備料長、焊口總數及中心線／外包範圍，另有 A4／A3 建議工單與 CSV。各焊口逐個納入閉合，新增間隙不混用 G1～G4。每個彎頭按一支原件備料，不假設切下半支可直接重用；A／B 整支件另一端直段，以及第三、第四個原件的前後直段可另外輸入；整支使用計雙端，對半切只計保留端。供料角度、Rc 及各直段須實測核對。搜尋管段下限預設 100 mm 是可調條件，並非 WPS 的通用下限。
- 可加入閥組、法蘭組或自訂零件，放在 A／B 端口或最多三段彎頭間直線，以實測兩個接管端面間的組立總長為準。已組好的配對件與墊片包含在總長，兩端額外焊口間隙／未包含的壓緊墊片厚度另填，扣除一次；端口零件取代該端原間隙。中間可置中或指定 A／B 側成品直管長，分段修磨留料另加。每個位置一組，最多五組；同位置的閥與法蘭可量整組總長合併。焊接與外部／組內螺栓接合分開計數，組內製造焊道不列現場焊口。
- 「介質與流體影響」（選填，在比較其他接法內）：選水類液體、黏稠液體或塑膠粒（氣送）。液體填流量、密度、黏度，每個接法多一行「壓損與比原接法差多少（換算成幾公尺直管）」；粒子顯示總轉角與會撞上焊道的焊口數。管壁厚預設 ASME B36.10 STD，焊道內凸預設 ASME B31.3 表 341.3.2 公制欄上限，可改填實際或承諾值；焊道內面可選原焊或內面平順。下方是按真實比例的焊口剖面（原焊與內面平順並排，液體疊流速分布，粒子畫實際粒徑）。點選一個備選接法後可產生「業主比較單」A4：結論一句話、兩接法並排（標出彎頭與焊口）、焊口剖面、壓損拆分、焊道內凸對結果的影響、可勾選的品質控制與第二頁計算依據。
- 計算方法：牛頓流體、等溫、滿管。摩擦係數 Churchill（1977），彎頭 Rennels & Hudson（2012）平滑彎管式（任意角度與半徑），焊道以 Idelchik 圖 4-14 銳緣薄孔板計（實際圓滑焊道阻力更小，屬保守上限），層流另加焊道窄段摩擦。公式與 Python `fluids` 1.3.1 的獨立實作逐值核對。氣送粒子的壓損取決於固氣比，不計算，只比較彎頭與焊道。結果用於比較接法，不是整條管線的水力計算。
- 含零件的搜尋預留零件總長、兩端間隙與最短直管，核對端面閉合及實際焊口上限（可調 4–24）。原接法放不下時說明缺少的長度或直線位置，引導比較其他接法；可找到但焊口超限時提供具體放寬按鈕，仍須明確選候選。C／E／P 零件、實測總長與分段管長同步顯示於互動 3D、加工頁、CSV 與 A4／A3；長材料、座標、接合表有續頁。零件外形只作辨識，不從示意外形計設備操作淨空；管路外包依管 OD，不含未知的零件外形。
- JSON v4 儲存指定零件完整資料，以及量測、方向、焊口、留料及比較條件；端口輸入完整但原兩彎頭接不成時，仍能保存量測並重開搜尋。候選選擇不存入專案，重開須重新確認接法。可載入 v1／v2／v3，舊版預設沒有指定零件；v1 保持原有理論交點基準，舊版補原有 5 焊口的比較預設。專案保存在本機瀏覽器，與接頭專案分開；加工輸出另要求所選配置通過檢查。

端口模式反算理想兩彎頭＋一支直管，依搜尋到的接法選較小總轉角並核對端口閉合；不檢查附近障礙或各材料間干涉。舊的理論交點模式中，Run／Travel 仍是中心線延長交點間距，不能直接填既有端面的間距。本版不包含跨越障礙、多管等距偏移、承插或螺紋接合。

接法建議以供料的整角或對半角列舉兩至四彎頭，求各直管正長度；三彎頭另取每 15° 首端轉向候選，四彎頭限同彎曲平面，沒有遍歷所有路徑或保證全域最佳。每個輸出均檢查末端中心位置及軸向閉合。可限制中心線超出兩端口 XYZ 包圍範圍的量，仍須另查現場障礙、材料自相交及安裝順序。原方案即使不符合建議搜尋的管段或繞出條件，也保留作比較基準；建議不是強拉補償。

本輪驗收：完整 448 項 Node 測試通過。新增 15 項涵蓋實測組長、兩端間隙只扣一次、端口原間隙取代、固定定位、缺長、必要直線、實際焊口／螺栓數、上限引導、JSON v4／v3 相容、CSV 名稱防公式及模型／列印的零件完整性。瀏覽器操作確認加入、修改、放不下清除舊加工結果、提高具體焊口上限、重新選接法、重開保留零件及單件 3D；320／390 px 可編輯並套用、無水平溢出。兩端閥與法蘭的 A4 五頁、五組長名稱零件及四個對半彎頭的 A4／A3 二十頁，均無內容越過頁尾。涵蓋多段搜尋、焊口上限、少繞路排序、專案保存及下一步引導；XYZ 1435／1000／2071、A +X／B +Y 的回歸案例在 5／6 焊口下無候選，放寬至 8 焊口後找到最少 7 焊口的三彎頭接法，另以獨立弧線數值積分核對端口閉合。四項模型檢查核對原方案失敗時仍能建立候選各零件、四彎頭的雙端直段與弧半徑、垂直管截面及單件切換。瀏覽器驗證收合列表的修正入口、未選接法時的加工導引、六個零件的加工與單件 3D、整組 3D 及分點連動；三彎頭 A4 五頁無溢出，320／390 px 加工頁保留全部零件與 3D 控制項，無水平溢出。「選接法」3D 另實測拖曳管身不誤開加工、點管身與 P2 編號開啟加工、自動旋轉／暫停、滾輪與按鈕縮放、鍵盤旋轉與置中、示意切換和 R1／R2 換接法；原兩彎頭及理論交點模式可用，320／390 px 圖面與控制項無水平溢出，加工頁 P2 與 E2 模型保持可用。先前已驗證量測修正、供料與向量、圖面拖曳、焊口及空間限制、原件直段、量弧換半徑、候選失效清除、專案相容及原／建議工單 A4／A3。尚未實管試切、試組或印表機實印。

切角以理想等半徑、圓形截面彎頭計算，端部直段另填。從保留端弧面起點量，各母線沿外表面弧量到切線；外背／內腹不是管壁內外緣。彎頭雙曲率表面無整片平紙等距展開，因此紙樣提供窄的分點弧長量尺，只讀中心線；可裁成 2–3 mm 細條貼合。切割在廢料側留線，再修到成品線；坡口與切縫未改變保留端的理論切角線。直管修磨留料只影響先下料長，未加入焊接收縮。數值與瀏覽器驗證不取代實物試貼、試切與試配。

偏移與切角基準參考 [Pipe Trades Pro 原廠手冊](https://m.media-amazon.com/images/I/B1OaucCUk7S.pdf)第 30–39 頁；彎頭公稱尺寸來源為 [Benkan 型錄](https://www.benkankikoh.com/en/wp-content/uploads/2016/07/PipeFittings-Catalogue.pdf)第 8 頁。

強拉／cold pulling 與管系柔性、拘束及接管負載有關，可參考 [LANL Process Piping Guide 附錄 F](https://engstandards.lanl.gov/esm/pressure_safety/Section%20REF-3-R0.pdf)第 127 頁起的說明；該文件的表格有其適用條件，本工具沒有套用其中的允收數值。

### 配管接頭與支材

現場放樣版：直管、理想圓形彎頭或同心直錐大小管母材與單支直管插接。提供圖像定位、3D、fishmouth、母孔紙樣／分點定位、直管補強板及已成形彎頭補強板。單位為毫米。

鋼構支材已加入圓管支撐、方／矩形管、H／I 型鋼、角鋼與槽鋼：母管保持封閉，按真實材料面計算端部，提供截面旋轉、3D 選面、逐面 1:1 紙樣與尺寸工單。尺寸與圓角按實際供料自訂，H／I／槽鋼首版使用平翼緣。詳見[鋼構支材使用說明](docs/steel-support.md)。

彎頭外沿齊線已修正管口孤立尖點的誤判，並加入依實際尺寸的修正卡；詳見[計算與修正流程](docs/elbow-edge-repair.md)。

## 開啟

- 線上版由本專案的 Sites 私人網址提供，網址見聊天中的完成訊息。
- 本機版：雙擊 `啟動工作台.cmd`。它在一個視窗內啟動本機服務，就緒後自動開啟 http://127.0.0.1:4173/ 工具首頁；使用期間保持該視窗開啟，關閉視窗或按 Ctrl+C 即停止。同一資料夾的工作台已在執行時直接開啟瀏覽器；連接埠被其他程式或另一個資料夾的工作台占用時會說明是誰（可先 `set PORT=4174` 再啟動）。啟動檔不使用 PowerShell。也可在此資料夾執行 `npm start`／`node scripts/serve.mjs`（加 `--open` 會自動開瀏覽器）。
- 需要 Node.js 20 以上。啟動檔依序找 PATH、`Program Files\nodejs`、使用者安裝位置與 Codex 附帶的執行環境，每個先試著執行一次；無法啟動（例如被防毒或權限阻擋）或版本太舊的會列出並略過。都不能用時說明安裝方式（https://nodejs.org/，或 `winget install OpenJS.NodeJS.LTS`），有 winget 時可按 Y 直接安裝。JavaScript 與 Three.js 已保存在專案，不需要 npm install、雲端資料庫或 API key。
- 瀏覽器使用目前的 Edge／Chrome。3D 需要 WebGL；無法啟用時仍可使用幾何與圖面。
- 直接雙擊 `dist/index.html` 可看工具選擇與啟動說明，完整計算請用啟動檔開啟。直接開 `joint.html`／`offset.html` 也會提示正確入口。

## 操作

1. 常用操作只填管徑、壁厚、長度、內插／外貼與角度。新專案預設 8 吋主管、4 吋支管、90°，不加補強板；舊專案完整保留尺寸與工藝。手機先顯示紙樣，按「修改尺寸」展開，填完按「完成，查看紙樣」。
2. ASME 公稱吋數帶入標準外徑，非標準才選「非標準／實測外徑」輸入 mm。NPS 不直接乘 25.4。在「插接定位」直接點管身及截面圆周；支管中心線也可選 A／B 同軸示意圖。數字微調、偏心、側轉與間隙收在精確設定。選中央預設後改母材長度／彎角會保持中央；點任意位置則保持實體距離。
3. 主工作區只顯示一個視圖：「紙樣放樣」、「3D 確認」或「紀錄與驗證」。設定分成母材尺寸、插接定位、補強板、加工、精度五頁籤。切換不清空資料；修改精確數字會同步圖卡和藍點。
4. 選支管、主管或板片，按「印這張紙樣 · 1:1」；上方「印 1:1 紙樣」也預選當前零件。選 A4／A3，方向自動省紙。校正說明頁可取消；重印只印紙樣。紙樣不混入驗證表、空白試配表或分點報告。
5. 「現場工單」另印尺寸、整毫米定位環與 12 分點＋360° 閉合表；空白加工紀錄的預設工單為一頁，已填工法、實測或處置文字才增加相應附件。試配分點可為 4／8／12／24 點，依角度對應工單放樣點。
6. SVG／DXF 收在紙樣的「檔案匯出」；專案儲存、載入與「完整計算報告」收在上方「專案與匯出」。完整報告仍可指定整段主管／支管包覆。數值精度不達標會停止製作出圖。
ASME 外徑選單涵蓋 1/8–24 吋，參考 [Benkan Kikoh 原廠尺寸表](https://www.benkankikoh.com/en/wp-content/uploads/2016/07/PipeFittings-Catalogue.pdf)與 [Rexal Tubes 尺寸表](https://www.rexaltubes.com/asme-b36-10-pipe-dimensions.pdf)。這是外徑對照，壁厚仍按實際管材輸入，沒有自動指定 Schedule。舊專案外徑精確吻合才顯示對應吋數，其餘保留實測模式；不近似吸附或改動尺寸。

只有捲尺時，可用「外周長換算外徑」直接套用 `周長 / π`，結果採實測外徑模式。常用尺寸可記住於本機瀏覽器；「同尺寸下一支」自動遞增接頭編號，保留尺寸。「復原修改」可回到上一組有效尺寸與位置選擇。分點表以解析公式逐點計算，不由顯示折線插值。

常用設定直接顯示；進階設定收合，展開或切換工作區保留尺寸。3D 支援拖曳旋轉、滾輪縮放、右鍵平移、視角與置中、透明／剖面／拆開零件。零件顏色對應母材、支管、補強板；彎頭／大小管的 A、B 另指兩端。

## 接頭與圖面基準

| 項目 | 外貼式 Set-on | 內插式 Set-in |
|---|---|---|
| 支管切口 | 主管外半徑＋徑向間隙 | 主管內半徑，另沿支管軸向伸入 |
| 主管孔工具半徑 | 支管內半徑＋每側孔口間隙 | 支管外半徑＋每側孔口間隙 |

外貼主管開孔採上述幾何基準。焊接接頭、連續流道與實際工法可能要求不同孔口细節，需核對。

- 主管軸為 X，基準端 X=0；既有 JSON／WebMCP 的 `jointPosition` 是支管軸在主管中心面 z=0 的虛擬基準 X，**不是外壁上的接頭點**。偏心時支管軸不與主管軸相交。外壁軸入點 X = `jointPosition + sqrt((mainOD/2)² − offset²) × cot(angle)`；UI 提供實際外壁位置輸入，內部轉回舊座標，舊專案不改動。
- 方位 0° 朝 +Z 管頂，90° 朝 +Y；正偏心在旋轉前沿 +Y。
- 主管包覆樣板的起縫在接頭方位對面，涵蓋整段主管。這是現有管材包覆開孔樣板，**不是主管捲板下料**。
- 支管樣板由同一個自由直端面量切深，周向按支管實際外徑。支管 0° 為主管 −X 方向在支管端面上的正交投影；由自由端朝接頭看，角度順時針增加。文字面朝外包覆時，紙上橫軸必須鏡射，角度向左增加。內緣虛線按相同角度投影到外徑包覆面，供壁厚修磨參考，**不是內徑包覆展開**。
- 預設魚口樣帶只涵蓋切口附近，附距自由直端的實體定位環線；不要將短紙樣上緣直接貼在自由端。15 mm 黏貼區只貼紙，周長仍為 π × 支管外徑。細點矩形為裁紙邊界，魚口為獨立開放實線，平面兩端不得加封口線。若紙張越過自由端，依正深度定位環線貼合。
- 平板彎製模式的補強板圓形／橢圓／長圓／圓角矩形指中性層平板外形，捲製後貼合主管；中性半徑 `Rn = mainOD / 2 + K × padThickness`。補強板紙面為 U→／X↓，標註預定外側；分片繼承同一母板的軸向／周向定位基準，對位線不得跨越孔內空區。
- 最低留邊只指中性面，內外面孔另外確認完整容納於材料內。分片輪廓已扣除孔內接縫，可分別裁切。
- 已彎板法線切孔的樣板貼在板外表面，展開半徑 `Ro = mainOD / 2 + padThickness`；孔線取整個板厚對支管圓柱的干涉包絡，包含板厚中間，不能只聯集內外兩面的孔線。K 不影響此模式；最低留邊按外表面量測。3D 實際孔壁沿主管徑向穿板厚。
- 主管局部開孔樣板與完整包覆使用同一條孔線，裁去孔外多餘紙面，不改比例。局部樣板附距主管基準端、接頭方位與周向位置，需依定位尺寸貼合。
- 裁切線代表成品幾何，尚未套用坡口、刀縫、粗切留料、焊接收縮或設備成形補償。

## 列印與現場使用

「印 1:1 紙樣」只產出選定零件的原尺寸拼接頁，另可勾選一張校正與貼管說明。「現場工單」獨立核對尺寸與量測；進階完整報告才包括參數、3D 畫面、幾何驗證及所有附件。分點表的內外切口深度皆沿支管軸向由直端面量測。360° 列為 0° 的閉合對位。

列印請選正確紙張、**實際尺寸／100%**，關閉「符合頁面」及瀏覽器頁首頁尾。每張樣板有雙方向 100 mm 校正尺、10 mm 拼接重疊區及對位標記。先量校正尺；只裁白邊，保留圖形重疊區，對準同號圈十字，再黏貼與包覆。拼接標記含 B／M／板片代號且使用透明圈，不遮切線。預設局部開孔圖可減少頁數，整段包覆保留為可選項。

SVG 以 `mm` 指定物理尺寸，包含輪廓外的校正尺。DXF 使用 `$INSUNITS=4`，金屬圖層為 CUT_OUTER、CUT_HOLE、CUT_FISHMOUTH，定位為 DATUM、SEAM、FOLD，裁紙框為 PAPER_BOUNDARY；魚口折線為 open。CAD 匯入後請確認單位為毫米並只加工金屬切線圖層。CSV 使用 UTF-8 BOM 供 Windows Excel 讀中文。

## 數學與驗證

主管表面為 `y² + z² = R²`。支管圓周各點沿軸線與內／外圓柱解析求交，同時以世界座標通用直線／圓柱二次方程獨立核對。展開 `u = R × φ` 再回包，檢查表面、閉合、回包及每段七個內部位置的採樣弦差；板外緣也包含於離散精度檢查。採样結果加入 10% 數值餘量，不宣稱嚴格全域誤差上界。

無效尺寸、非單一封閉近側交線、有限主管端部越界、內插碰到對側內壁、補強板自我重疊及板孔切穿外緣會停止出圖。取樣弦差超限會停止製作匯出。

本版處理理想直圓管、有限圓形彎頭及同心直錐幾何，**不是承壓補強設計或焊接強度核准**。材料、壓力、溫度、腐蝕裕度、外力、疲勞、規範補強面積與焊接尺寸尚未實作。實測橢圓度、成形試片及現場工法需另行核對。3D 網格供操作預覽，匯出數據来自解析幾何，不由顯示網格反推。

「幾何可出圖」只表示幾何與數值輪廓檢查通過，不代表加工公差或現場試配已通過。主管孔採斜向圓柱穿壁求交；厚壁斜插仍需按內外孔緣修磨，不能假設沿主管外表面法線直接切孔就一定能裝入。

## 保存與資料

參數在瀏覽器計算，不上傳接頭資料。有效專案會保存於此瀏覽器的 localStorage，重開可恢復；位置模式另存為與該組參數相符的介面偏好。請另用「儲存專案」下載 JSON。載入 JSON 完整保留原外徑與虛擬軸基準，換算顯示實體距離並採自訂位置，不自行置中。載入專案重新驗證，錯誤檔案保留原工作。瀏覽器下載的 SVG／DXF／CSV／HTML／JSON 由使用者自行管理。

## 直管加工與試配

「加工試配」增加沿軸粗切留料、預估標線／切磨最大偏差及實測刀縫記錄。留料、偏差、工法根隙及實測值預設空白，空白與明確填入 0 分開保存。沿軸剩餘留料估算為留料減兩項預估偏差；不是根隙、紙樣精度或加工保證。刀縫不自動轉成砂輪中心線偏置。

填入留料後新增「B 粗切／修磨」紙樣。每個角度取成品內／外緣較深側，再沿支管軸留料；直圓母管的深度對支管壁半徑為凸函數，因此這兩個壁緣包容徑向穿過全壁厚的留料需求。長虛線 `ROUGH_CUT` 為粗切線，實線 `CUT_FISHMOUTH` 為成品外緣，內緣短虛線另供修磨。紙框隨留料擴大，不移動自由直端基準與定位環。此幾何假設不涵蓋砂輪偏擺或任意刀具走向，需試作校正；也不可直接套用未實作的彎頭母材。

試配與點固後根隙可分別填 4／8／12／24 分點，從魚口樣帶的同一 0° 母線定位；分點按鈕對應 3D 切口位置。橙色點與紙樣 `T` 記號只選點固參考母線，定位環上的 T 不是實際焊縫，數量與順序由工藝單決定。WPS 編號／版次、量測方向／位置與根隙上下限均由使用者填入，程式只核對數值是否在填入範圍內。缺肉或超限標示需處置；處置文字不會覆寫超限結果。坡口、鈍邊、焊道尺寸與點固順序只作工藝記錄，尚未產生坡口加工曲面或焊接強度計算。

改實體尺寸會清空舊量測、切口檢查與處置；改量測方向／位置也要求重測。取樣精度的變更保留實測值。「同尺寸下一支」與常用尺寸保留工藝設定，但不沿用實測值。新版 JSON v2 保存工藝與紀錄，舊 v1 可繼續載入；復原與重開會保留匹配當時尺寸的紀錄。加工 CSV 包含工具、留料、偏差、刀縫、工法、根隙、切口狀況及處置。報告增加加工工藝頁、試配紀錄頁；長處置與焊接順序文字依實際換行分頁。

## 紙樣與介面簡化版

支管短紙樣使用向下取整到 1 mm 的 D 定位環，並確保定位環在內外成品切緣之前的保留材料；取整只移動紙面基準，不更改成品深度、周長或切線。主管局部紙樣裁紙範圍改為同時容納外孔與完整內緣修磨參考線，避免厚壁淺角插管失去內緣參考。

純紙樣自動方向依當次選定零件的紙樣頁數選擇；分別印支管與主管可各自選最省紙方向。10 mm 印表邊距、2 mm 圖形留白與連續重疊拼接保留原毫米比例。8 吋／4 吋、90° 的支管紙樣：A4 橫式兩張或 A3 橫式一張，校正說明另加一張。工法紀錄錯誤會停止工單與完整報告，但不阻擋已驗證的純幾何紙樣；留料線僅使用有效的沿軸留料設定。

驗收：93 個 Node 測試通過（匯出套件另含 21 組檢查）。新增獨立 3D→紙面映射、全點保留、同號十字的跨頁座標、毫米比例、整毫米定位環、A3 單張、說明頁不改紙樣座標、單頁工單及 24 點兩階段紀錄測試。瀏覽器檢查手機 390 px 收合設定、無根頁水平溢出、3D 切換、錯誤工法不阻擋紙樣、全部板片的 A4／A3 直橫紙樣與工單頁尾。尚未進行實管紙樣試貼、印表機實印或現場試切。


## 彎頭母材與直支管

母材型式選「彎頭」，預設 90°、8 吋長半徑 R=304.8 mm、4 吋支管插在外背中央。90° LR／SR 按 Benkan 原廠公稱 A 尺寸表帶入，1/2、3/4 吋 LR 的 A 均為 38.1 mm；沒有原廠值時改實測模式。這是理想中心線半徑基準，實物供料尺寸需核對。45° 模式使用自訂理想圓弧與實測 R，不把原廠 45° 的中心至端面 B 尺寸誤當半徑。

先選「彎頭中央」或「指定 A 端起的背脊距離」，再選外背、內腹、左側、右側或其他截面方位。A／B 端在 3D 標示；由 A 朝 B 看、外背在上時，截面 90° 在左、270° 在右。自訂背脊距離在半徑或管徑變更時維持量測意圖；指定 β 角度會轉成同一實體距離。直管与彎頭各自保留設定，切換不混用直管的虛擬軸位置。支管角度相對接頭處的當地切線，旋向及間隙放在進階設定。

支管可印原毫米比例的外徑包覆 fishmouth 紙樣，保留同一自由直端、整毫米 D 定位環、內緣修磨參考、15 mm 貼紙舌、100 mm 雙方向校正尺及拼接對位。8／4 吋、90° 常用案例的魚口樣帶為 A4 橫式兩张或 A3 橫式一張；校正說明頁可取消。紙面仍按文字向外包覆的手性鏡射。

彎頭母孔使用獨立定位工單：從 A 端沿外背 S背或內腹 S腹確定 β 截面，再從外背基準繞同截面量 U。工單同時列出左／右短弧距離，避免接近 360° 的點繞量整圈。紙面定位索引圖是示意，禁止匯出成母孔 CUT_HOLE 或整片 1:1 包覆樣板。理想環面具有雙曲率，整片不能無失真攤平；參數圖的 Rcβ／rφ 也不是現場背脊距離。參考 [MathWorld Torus](https://mathworld.wolfram.com/Torus.html) 的環面度量與曲率。

預設工單為兩張 A4 直式：一張支管 12 分點＋360° 閉合，一張母孔 24 區段＋閉合定位。各點由解析求交重新計算，不取顯示網格或折線插值。母孔稀疏點間的 3D 弦差估計另列，不能冒稱達到核心密採公差；厚壁需核對內緣與壁厚，不能沿外壁法線直接割穿。已填留料、刀縫、WPS、試配或處置才附加工頁；短備註併在最後加工頁，長文字完整分頁。

幾何使用有限環面與直線四次求交，分離近／遠根並以表面殘差修正。檢查端部越界、內插遠壁碰觸、保留支管再入其他彎臂及壁厚干涉；一般斜向使用有限壁厚探查與停止位置細化，外背正向有額外解析單調性排除。數值精度按每段七個內部點、1.1 餘量與自動加密檢查，不能視為連續全域嚴格證明。較複雜計算在背景 Worker 執行，連續輸入只保留最新結果，未完成時停用出圖。

彎頭補強板提供已成形板的 3D 與分點定位，詳下節。目前不提供連續全壁厚粗切留料包絡、真實成形橢圓度、坡口曲面、刀具運動、焊接收縮或承壓設計。留料與加工偏差仍可記錄，但不產生未驗證的彎頭粗切線或 CSV 粗切深度。實體尺寸、位置或半徑改動會清空不匹配的試配紀錄。

新增程式為 `elbow-geometry.js`、`elbow-input.js`、`elbow-field.js` 與幾何分派／Worker。測試涵蓋獨立圓截面基準、有限彎臂、遠壁碰觸回歸、3D 與紙面映射、定位短弧、精確分點、頁數、長備註、過期紀錄及禁止不支援的展開／粗切。以上是數值與數位圖面驗收，尚未做實管試貼、試切、試配或印表機實印。

## 彎頭端部同軸與支撐管

新增「對齊 B 端中心線」及對稱的 A 端選項。支管從彎頭外背沿該端中心線反向延伸，軸線通過端面圓心；這是外背插接或 dummy pipe 的配置。程式同時反算插接截面與當地夾角，改外徑或彎曲半徑後重新求交。3D 虛線及平面示意呈現端部參考中心線，另核對垂距及方向偏差，避免把平行的兩條軸線當成重合。

同軸條件與接法獨立：可選外貼開孔、開孔內插，或外焊支撐且母管封閉。內插保留凸入量與孔口間隙；有限端面、遠壁與保留管身干涉照常檢查。封閉母管不產生母孔，定位工單使用支管外徑在母管外壁的貼合足跡，明示禁止依足跡切除母管；不套用內壁開孔的限制。三種接法均可印直支管 1:1 fishmouth 紙樣，彎頭定位仍使用分點量距工單。

理想環面幾何採 `L = sqrt(2Rr+r²)`、`δ = atan2(L,R)`；B 端定位截面為 `γ−δ`、當地支管夾角為 `180°−δ`。8 吋、R304.8 mm、90° 彎頭的 B 同軸位置為 β47.358785°，支管夾角137.358785°。45° 彎頭即使軸入點落在母材上，4 吋完整魚口仍可能跨出端界，會停止出圖；不放寬端界來製造無效樣板。

驗收：167 項測試通過，另以獨立圓截面算法核對 12 組核心及工單資料。新增回歸涵蓋真同軸與平行偏移、尺寸重算、有限45°／90°端界、內插端面停止、封閉母管無孔與精確足跡、幾何保存及魚口匯出。瀏覽器確認 390 px 手機無根頁水平溢出、同軸切換與半徑重算、無效模型停印與恢復；A4 工單不碰頁尾，1:1 魚口紙樣保留毫米比例與拼接。數值與數位圖面檢查不代表實管試配或支撐荷載、焊接強度驗證。


## 圖像定位與已成形彎頭補強板

母材、接法、A／B 同軸、支管角度與補強板外形均可看图選擇。自由孔位可點弧線／管身，再點截面圓周；滑動頁面不會修改位置。圓周與管身亦可用方向鍵，Shift 加大步距；精確數字仍可輸入。從 A 朝 B 看，0° 在上、90° 左、180° 下、270° 右。直管包含偏心對外壁入點的修正。

彎頭補強板固定為已預先成形的雙曲率板，內面貼母材，外面半徑增加板厚；孔沿支管軸穿厚，兩面孔線各自求交。四種外形指角度定位座標中的圓／橢圓／長圓／圓角框，實際邊界以曲面分點製作。支援單片、接縫沿 A→B 或沿截面圓周的兩片。B 端同軸預設建議長圓或橢圓；圓框若跨半周或端界會停圖。

外緣留邊用距支管軸的解析二次式在完整板厚上取最小，再以連續段位移上界證明保守下界。孔口近側拓撲仍用有限層與站點探查，不聲稱全域證明。板厚／端界／孔緣／支管自由端不足均停止整個接頭出圖。

「成形補強板定位」提供索引、內外孔點與獨立 A4 工單；雙片共用接縫頁列內外面八個精確端點。S背以母管 A 端為截面基準，再量該面短周向弧。成形板不是平板下料或 1:1 包覆紙樣；不計算中性層平板面積、補強強度或承壓面積。

## 同心大小管母材

選「大小管」，A／B 兩端各用 ASME 吋數或實測外徑，另填兩端軸向長度與真正法向壁厚。`jointPosition` 在此模式表示外壁接觸點的實體 X；不使用直管的虛擬中心面基準。支管角度以接觸處母線切線為基準，90° 為法向，另可側轉。支援外貼開孔、開孔內插、封閉外焊支撐。

內外母材是平行錐面：內半徑沿固定 X 減去 `wall * sqrt(1+k²)`。解析二次求交剔除無效負錐片，檢查有限端面、遠內壁及孔口穩定性。母材以等距扇環展開，提供局部孔口紙樣與整圈紙樣；裁紙框雖為矩形，孔線保留真實扇環座標。定位十字附 A 端母線距離／φ／當圈 U；這是已成形外壁纸樣，並非鋼板中性層下料。[錐台基準](https://mathworld.wolfram.com/ConicalFrustum.html)。

模型適用理想直錐台，不代替有直段、圓角、橢圓變形或偏心的實物異徑管。錐管補強板與連續全壁厚粗切包絡尚未提供。現場工單列支管12分點及母材24分點，另按已填工艺及實測資料增加附件。幾何變更會清除不匹配的舊試配紀錄，數值加密保留實測值。

圖像／大小管／成形板新版驗收：210 項測試通過。實際 390 px 手機驗證中央保持、精確數字同步與連續鍵盤操作；根頁沒有水平溢出。A4 單片25点板表、雙片8点內外接縫、大小管及完整彎頭報告均未碰頁尾；A3局部錐面孔口紙樣保留真實毫米尺寸及雙向100 mm校正尺。以上仍是數值與數位圖面驗收，實管加工與印表機實印尚待現場確認。

## 桶槽分件、焊道與 BOM

桶槽頁新增第 4 步「分件與 BOM」。可建立板件、管段、支承及採購附件；分件有固定編號、材質／密度、規格、每組數量與單重。全槽數量按「每組數 × 組數」計算。平板、直管、圓棒及環板可按幾何估重；異形／成形件與採購件使用實測或供應商單重。空白保留未知，不能當成零；明確填 0 kg 才表示確認為零。重量合計為成品估重，不含焊材，筒身未扣開孔。

焊道連到組內分件或筒身、端部、現場接件，可填角焊腳長／對接厚度、單道中心線長或圓周直徑、重複道數、製程及 WPS 索引。同件捲板自接須指定兩個不同接合邊。已填齊長度和焊接尺寸的焊道才計入製作工法的焊材估量；未知項保留在焊道索引。坡口與熔敷密度沿用製作工法及槽體密度，異材接頭與多製程分道仍需依 WPS 核對。

「計入方式」選支承或某個管嘴時，分件明細取代該項的概算重量與焊道，避免重複；管嘴位置、開孔、補強板與蓋板／吊桿可各自指定取代，未指定時仍各自管理。模板可另存 JSON，再匯入其他桶槽；匯入／複製先當新增附件，操作者需核對歸屬。分件資料與原板備料保留在專案中。整槽 BOM 合併槽體、管嘴、既有工法附件與明細，可下載 CSV、單獨預覽／列印分件單，也會併入完整估料單。舊版 V-1102 案可從原圖參考區「補入原圖分件草稿」，保留已修改的槽體及管嘴尺寸。

V-1102 範例登錄 11 組組件、33 項分件與 28 項焊道關係，包含兩組分件支承、耐磨捲板、銘牌、接地、H1／SN1 盲蓋附件、防渦流器與五組 LWN。原圖未能確認的異形尺寸、螺栓配置、單重與焊接資料仍留空；不是核定製作圖。分件平板、環板與已確認異形毛坯已併入共用原板排料，材質、板厚及密度不同時分開用板。新分件尚未建立完整 3D 位置，所以不據此放行整槽外包、重心與施工吊運。AUTO 焊道為原工法群組概算，尚未逐道定位。完整製作圖仍需補孔位／外形、幾何位置、逐道詳圖及工程審核。


### 分件板料與原板採購

「分件／焊道」內的平板及環板可按成品尺寸各邊加留料，或填已含留料的矩形毛坯包絡；異形／成形件必須指定已確認的展開毛坯，不能由單重推算外形。外購成品與管棒料不占原板。分件留料留空時沿用整槽設定；指定毛坯不再重複加留料。V-1102 耐磨板的 830 × 250 為原圖已註明展開尺寸。

槽體、原工法附件與分件共用同一份排料帳：只有相同材質、板厚、密度可共板／使用餘板。材質僅統一大小寫及空白，不自動把不同規範材料當成同料。相同材料密度不同時隔開並提醒核對。各材料組可各自指定 4′×8′、5′×10′、5′×20′；未指定者沿用預設尺寸，刀縫仍採全槽設定。

### 整張、餘板與裁切料的報價採購

「選板與排料」新增三段採購工作區：填供料／報價、比採購方案、已套用清單。每筆可填材質、板厚、可用矩形長寬、數量、每張／片報價；可另記供應商／庫位、料號、密度、備註及本筆訂購一次費用。常見 4′×8′、5′×10′、5′×20′ 可直接帶尺寸，也可自訂。所有報價使用同一幣別，不混加匯率；換幣會清空舊價並提示重新填報。金額按兩位小數四捨五入，一次費空白以 0 計。

餘板／裁切料一定按有限數量比較，數量空白不能供料，0 表示無庫存；整張數量空白明示不限量、仍需確認供量。單價空白是未知；自有餘板若要按零取得成本比較，必須明確填 0。不同材質、板厚或密度不共料；同材同厚有多種密度時，未指定密度的料源不能自動分給任何一組。

每組比較「只買整張」「只用餘板／裁切料」「混買」，按實際可排入的整張／整片加報價計總額。一次費對每筆用到的料源只收一次；未使用的報價不計。顯示各筆使用量、尚餘量、餘料／刀縫損耗、可保留矩形餘板與已知焊長。自動板件會試目前、常用板型與料源尺寸重分片；固定分件毛坯維持原尺寸。建議依已報價的板料支出排序；同價優先短焊長與少片數，沒有焊接／加工報價不宣稱整體製作成本最低，也不扣廢料回收價。

套用後按每張實際尺寸、料源與價格重放排料，BOM／原板編號、座標、採購張數／重量、CSV 與兩種估料單共用同一份資料。供料尚餘＝原始可供量−本次採用量；重算、存檔與列印不會重複扣庫存。修改已採用料源的尺寸、數量、單價、費用，或修改幣別、刀縫、毛坯使原方案失效時，明示待重比，回到未報價的整張估排，不沿用過期金額。只改料號／庫位等文字，或新增、修改未採用的比價料，仍保留已驗證排法。

演算法是含刀縫、可轉 90° 的矩形包絡啟發式排料，不在圓孔或異形缺角內套料。餘板輸入應先扣掉不可用邊與孔洞，僅填完整可用矩形。每組報價比較最多 1,500 片，料源數×片數超過 20,000 要分批；最多比較 10 種自動分片基準、混買搜尋約 900 節點，達限制會顯示，未找到完整排法不當成零張／零成本。建議只含已確認毛坯，尚未完成的分件、採購件或成形封頭另列。

### 在展開圖直接拖曳接縫

選板頁的「在展開圖調接縫 → 拖曳接縫」會顯示 L 縱縫及 C 環縫的拖曳把手。環縫上下移動，只調整相鄰兩圈板高；縱縫左右移動，只分配相鄰兩片弧長。第一片的合口縫可跨越 0°，其他縱縫保持原位；單片成圈則旋轉該圈合口縫。槽長、圓周、根隙、管嘴／補強位置及焊道數保留，板片不可互相穿越或變成負尺寸。

圖上的淨距讀值跟隨目前選取的接縫，按開孔與補強板各自的包絡、焊趾外伸、筒身焊道寬度及施工淨距計算；即使其他焊道更近，仍量測選中的這道。顯示最近控制包絡、相鄰圈錯縫中心距，以及相鄰板片的實際毛坯尺寸；讀值可隨頁面捲動保持在圖上方。距離不足、板邊過小、錯縫不足或毛坯超出目前板向的可用原板時標紅。「同步 3D」可在展開圖旁顯示同一整槽、管嘴及接縫，移動時保留使用者的鏡頭方向。

選接縫後可輸入中心位置細調；縱縫位置為從固定 0° 沿中面圓周量起的 mm，環縫由 A 端筒身板邊／筒身下緣量起。方向鍵每次 1 mm、Shift 每次 10 mm。每次完整拖曳是一個復原步驟；Escape、指標取消或擷取中斷會復原該次移動並清掉尚未執行的畫面更新。移動中暫不自動保存，放開後重算共用模型；不合板料／板邊／錯縫條件時保留紅色圖面並阻擋出單，施工避讓衝突則在加工單明列。施工尺寸留白仍是待確認，不把未填當成允許零距離。

接縫標紅時，放開把手會顯示「最近可行位置」及藍色虛線預覽，列出目前／建議位置、移動方向與距離、控制管嘴或補強板的焊趾淨距，以及仍待處理的其他接縫。按「移到建議位置」才套用，可復原。計算限定只移所選接縫，按 0.01 mm 定位精度求距離最近的可行區間；管嘴、補強位置、固定 0° 及圈／片／焊道數保留。檢查目前原板板向、修邊／板端留料、最小成品板邊與相鄰圈錯縫距離。環縫移動同時檢查兩側縱縫的長度變化，不新增或加深它們與其他管嘴的施工干涉；既有無關衝突仍另列，不表示整槽已全部可施工。

只移這道仍未找到位置時，提供「調整分圈／分片」入口，使用原有多接縫搜尋；不會自行增加焊道。未填尺寸的建議標示「依已填尺寸」，仍需補齊核對。藍色線僅是預覽，套用後才更新共用的板片／焊道模型、原板配置、2D、3D、加工單及專案保存資料；數值定位精度不等於現場量測或加工公差。新增 15 項最近位置與套用回歸測試，全套 853 項中 852 通過、1 項既有跳過；背景桌面與 390 px 手機實測拖曳標紅、建議／套用／復原、3D 與加工單同步。
