# 彎頭外沿齊線計算與修正流程

## 有效的管口接點

A／B 端外沿齊線是支管平行於指定管口軸線，且兩根管的同側外輪廓齊線。偏移距離保持 `(主管外徑 − 支管外徑) / 2`；8／2 吋為 79.4 mm。這個條件不等於兩曲面處處相切。

封閉外焊的外背、±Z 或外背側向組合，可以在所選管口有一個孤立的魚口尖點，整條裁線仍連續閉合。新版以端口平面解析求交處理該點，不移動位置或放寬一般失交條件。內腹方向仍使用正距離的近側外壁出口，不把管口的遠側零距離根當成魚口。

側向尖點附近採四次角度映射加密。3D、紙样周長座標、內緣參考與精度探點全部保留真實角度 θ，不能把非均勻站點的索引當成均勻角度。現場 12／24 等角表仍逐點精確求交，1:1 支管紙樣與自由直端基準不變。

## 開孔與內插的獨立條件

外壁輪廓齊線成功不保證完整流通孔或內插切口成立。主管內半徑、支管實際壁厚、孔口每側間隙共同限制內壁交線：

- 外貼開孔使用支管內半徑加每側孔口間隙；薄主管壁或較厚支管壁可能仍可形成封閉母孔。
- 內插魚口使用支管外緣與主管內壁求交；齊線外缘可能越過主管內壁範圍。
- 有限管口、保留管身、內插端面及精度檢查仍保留。相同外徑造成非孤立相切、母孔內緣恰碰端界等案例仍停圖。

錯誤依階段回報 `branch-cut`、`mother-opening`、`finite-end`、`body-interference` 或 `tangent-open`，並顯示實際內半徑與需要的外沿範圍。一般厚壁 8／2 吋案例的主管內半徑為 103.55 mm，而內插支管最遠外沿為 109.55 mm。

## 修正卡

定位失敗回到原 A／B 截面，而不是解鎖自由定位或導向不相關欄位。過大支管回到 ASME 尺寸選單；內插凸入碰撞直接導向凸入量；加工設定與試配紀錄分別導向其實際表單。

開孔／內插的退讓建議依實際內壁空間計算，並明示另留 1 mm 定位餘量；這不是焊接根隙或加工許可。候選保留原接法與其他尺寸，經完整幾何和製作精度檢查才套用。若依然失敗，原尺寸保持不變；計算期間使用者改尺寸也不套用舊候選。

「改同軸」明示改變定位。「改為外焊支撐・母管不開孔」明示改變接法及取消凸入，不由程式默默代換。補強板建議只改板留邊，仍檢查整個接頭。

手機尺寸編輯時的預覽隨頁面捲動，避免固定預覽遮住接法或修正按鈕；A／B 截面浮窗保留圖像操作。

## 驗證

完整 329 項測試通過。新增回歸涵蓋 A／B、45°／90°、外背／±Z／斜向、封閉與開孔、真實尖點、真角度紙面、精確分點、端界、相同外徑及製作精度停圖。獨立端口平面算法核對交線，另以每段 31 個內點密採六組方向，最大弦差皆低於回報值與 0.1 mm。

瀏覽器實際確認外背、側向齊線可出圖；內壁失交返回原 B 截面；8／2 吋內插退讓 7 mm 後保留接法並通過完整計算；明確改封閉外焊可恢復精確齊線。這些是理想幾何與數位操作驗證，實管及焊接仍按既有製作流程核對。
