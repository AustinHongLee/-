# 直接在模型定位

工作台預設開啟模型。點灰色母材外壁直接移動支管接點；拖金色接點改位置、拖藍色端點改方向。拖背景只轉視角。彎頭 A／B 管口上的按鈕套用真正端部中心線重合，先按「自由定位」才解除同軸條件。直管調斜度限制在目前的軸向平面，換側以點母材外壁完成。

側欄先列母材、ASME 管徑、實際壁厚及必要長度；接法、補強板、加工與精度分頁。精確位置與角度、接頭編號、版次及常用尺寸摺疊保留。手機修改尺寸時模型置頂，操作標記至少 44 px，管口標記避開拖曳把手。

點選只使用完整外壁代理曲面，再投影至理想解析外壁。孔內面、補強板、分解零件及管端面不作新孔位的目標。直管保留偏心量並修正截面方位；彎頭與同心大小管沿用核心的局部座標基準。拖曳期間顯示定位預覽，放開後才重新計算完整魚口；計算中停用位置操作與出圖，防止舊結果覆蓋新設定。尺寸失效時仍保留有效母材供修正，失效母材不留下舊支管。多指手勢取消點位操作。

驗收：254 項 Node 測試通過，其中 13 項新增測試驗證外壁反算、偏心修正、方向往返與有限 A／B 端。實際瀏覽器驗證彎頭點管身、拖接點、拖方向、拖背景不改尺寸、A／B 真同軸、無效端界停止出圖、偏心直管與大小管點位、方向鍵及 390 px 手機無水平溢出。A／B 同軸誤差約 1.7e-14 mm／1.3e-14°。這些是理想幾何與操作驗收，尚未做實管試配或實印。
